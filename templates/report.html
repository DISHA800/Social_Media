Social Media Analytics Platform

Final Project Report

1. Introduction

This report details the design, implementation, and findings of an AI-powered Social Media Analytics Application. The platform dynamically ingests social media data and processes it through multiple analytical modules to derive actionable intelligence.

2. Problem Statement

Develop a full-stack Social Media Analytics Application integrating multiple analytical modules to process and analyze data from platforms such as Facebook using APIs (Apify), providing visualizations and automated reports.

3. Case Study Description

  • Topic/Brand Name: NASA (National Aeronautics and Space Administration)
  • Platform: Facebook
  • API Source: Apify Facebook Pages Scraper API
  • Data Volume: 50 latest posts and interactions.

4. System Architecture

The system utilizes a Python Flask backend to handle routing, authentication, and API integrations. The frontend is built using HTML5 and Bootstrap 5 for responsive design. Data visualization is powered by Plotly. Data is stored in local JSON format simulating a NoSQL environment.

5. Methodology

The application implements several Machine Learning and NLP heuristics: TextBlob is used for polarity-based Sentiment Analysis. NetworkX is utilized to build co-occurrence graphs for Network Analysis, and Eigenvector Centrality is calculated to rank Influencers. Scikit-learn's TF-IDF vectorization and Cosine Similarity drive the Content-Based Recommendation system.
